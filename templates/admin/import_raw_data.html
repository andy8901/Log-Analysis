Import Historical Data

Backfill flights that only exist as an already-extracted spreadsheet — the same ~150-column format this app's own Export Raw Data produces, or your original desktop Multilog tool's export. Each row becomes a flight that counts in every dashboard (totals, trends, range, battery-at-failsafe, thrust/GPS issue counts) exactly like a real upload. There's no raw log behind it, so it has no 3D replay and no Word/Excel/video export — it's data for the dashboards, not a full report.

Columns it looks for

Matching is case-insensitive; a missing optional column just falls back as noted.

FieldColumn names it acceptsRequired?
MSNMSN, Drone MSN, Serial Number, Serial No, SerialYes — a row without one is skipped

Drone ModelDrone Model, ModelNo — defaults to "UNKNOWN"
Flight DateFlight Date, DateNo
Reported ByReported By, ReporterNo
Log NameLog Name, Filename, File NameNo

All other recognized Multilog columns (Max Home Distance (m), Battery Failsafe, Min/Max Voltage (V), Potential Thrust Loss, GPS Glitch Count, Distance Travelled (m), Flight Time (min), Avg Baro/GPS Alt (m), Avg Current (A), ...) are read directly by column name — keep the original Multilog headers for those.
