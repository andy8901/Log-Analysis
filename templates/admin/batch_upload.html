Batch Upload (Folder)

Run a whole folder of raw flight logs (.bin/.log/.tlog) for one drone through the same diagnostic pipeline as a normal department upload, in one go — each file becomes its own flight with a full report, 3D replay where supported, and flight-investigator analysis, exactly as if it had been uploaded one at a time.


All files in the selected folder are treated as logs for the same MSN — this mirrors how a folder of logs pulled off one aircraft's SD card is normally organized. To process logs for several drones, repeat this per drone. Each file still has to pass the usual checks (readable log, valid type); any that fail are listed after submitting, and the rest still complete.
