Import Warranty Data

Bulk-loads the warranty tracker spreadsheet so a flight's report page can show live warranty status for its drone. Covers every drone the tracker lists, even ones that have never had a log uploaded through this app yet -- warranty data isn't tied to a department, only to the customer and MSN.

Sync from Google Sheet

Pulls the tracker straight from a live Google Sheet, no export/upload needed. The sheet must be shared as "Anyone with the link can view" — there's no Google sign-in wired up here, so a private sheet will fail with a clear error instead of silently returning nothing.

Or Upload a File

Columns it reads

Matching is case-insensitive. Any Warranty Expiry / Days Left / Status / Drone Age columns in your sheet are ignored on purpose — those are recomputed fresh from Purchase Date + Warranty (Months) every time they're shown, so they're never out of date.

FieldColumn names it acceptsRequired?
Customer NameCustomer Name, CustomerYes — a row without one is skipped
MSN NoMSN No, MSN, MSN Number, Serial NumberYes — a row without one is skipped
Product NameProduct Name, Product, ModelNo
Purchase DatePurchase DateNo — warranty status can't be computed without it
Warranty (Months)Warranty (Months), Warranty Months, WarrantyNo — same as above

Re-importing an updated tracker (corrected date, renewed term, ...) overwrites the matching (Customer, MSN) row rather than creating a duplicate.
